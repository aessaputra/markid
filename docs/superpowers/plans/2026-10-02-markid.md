# MarkID Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bangun editor watermark lokal untuk foto dan PDF dengan UI Inggris sederhana dan preview hasil sebelum unduh.

**Architecture:** Satu aplikasi statis dengan state/geometri/renderer watermark bersama. Adapter gambar memakai native decode dan fallback HEIC lokal; adapter PDF memakai PDF.js untuk preview serta pdf-lib untuk embed watermark PNG tanpa merasterisasi isi halaman. Pisahkan job/resource lifecycle agar replacement dan export tidak menghasilkan state stale.

**Tech Stack:** Svelte 5, TypeScript, Vite, Tailwind CSS v4, Canvas 2D, heic-to, PDF.js, pdf-lib, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-02-markid-design.md` (baca bersama rencana ini).

## Global Constraints
- Input maksimum 10 MB = 10.000.000 byte, satu file sekali proses.
- JPG/JPEG, PNG, HEIC/HEIF, WebP, AVIF, PDF adalah scope, bukan dukungan yang sudah terbukti.
- JPEG maksimum 1 MiB = 1.048.576 byte; batas ini tidak berlaku pada PDF.
- Semua UI copy memakai bahasa Inggris sederhana: label, tombol, helper, status, error, tooltip dan accessible name. Gunakan sentence case.
- PDF encrypted/berpassword ditolak: `PDF is locked. Unlock it and try again.` Tidak input password atau bypass proteksi.
- Tidak upload, analytics, remote image, backend, database, akun, batch, flatten PDF, atau PWA offline. Resource lokal; hanya preferensi tema disimpan.
- Target browser: Chrome 111+, Safari 16.4+, Firefox 128+. Feature detection tetap diperlukan; in-app browser tidak dijanjikan.
- Jangan mengubah `references/watermark-identity`. Spike tetap throwaway.
- Jangan menyalin kode AGPL dari alam00000/bentopdf. Implementasi sendiri dari kebutuhan dan API library; audit lisensi library/aset.
- Ikuti skill design-taste-frontend, tailwindcss-mobile-first, tailwind-design-system, svelte-code-writer dan test-driven-development saat eksekusi. Verifikasi API terkini dengan find-docs.
- Pengujian desktop/engine tidak menggantikan perangkat fisik. Jangan klaim production-ready sebelum release gate.

Kontrak dasar berikut ditetapkan di Task 1. Caller tidak mengakses decoder internals:
```ts
export type Size = { width: number; height: number };
export type Point = { x: number; y: number };
export type Watermark = {
  text: string; fontFamily: string; sizeRatio: number;
  x: number; y: number; angle: number; opacity: number; color: string;
}; // x/y normalized top-left display space, center anchor; angle clockwise degrees
export type LoadedImage = {
  kind: 'image'; size: Size; source: CanvasImageSource;
  resized: boolean; dispose(): void;
};
export type ExportResult = {
  blob: Blob; kind: 'image' | 'pdf'; size?: Size; dispose(): void;
};
export type ImagePolicy = { maxSide: number; maxPixels: number };
```
All image sources after decode are orientation-normalized. No additional EXIF transform in renderer. Policy values are explicit experiment configuration, not universal safety constants.
